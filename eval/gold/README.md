# Эталон (gold standard)

Поля совпадают с будущими таблицами `labels_gold_people` / `labels_gold_frames` (их делает Айгерим).

## gold_people.csv — одежда по кропам (по одной строке на человека и разметчика)
| поле | значение |
|---|---|
| video_id, snapshot_id, person_idx | ключ кропа; person_idx = индекс рамки в `boxes` среза |
| color, color_2 | цвет верха из словаря (14 цветов + unknown); color_2 можно пустым |
| type | тип верха из словаря (12 типов + unknown) |
| visible | `да` / `спиной` / `частично` / `не видно` |
| box_h | высота рамки в пикселях |
| labeler | имя разметчика |

Один кроп размечают двое независимо; 50 кропов — все трое. Несколько строк с одним ключом = разные разметчики.
Итог для бенчмарка = большинство голосов по полю; ничья = поле не оценивается (идёт в отчёт как «спорные»).

## gold_frames.csv — счёт людей на кадре
`video_id, snapshot_id, true_people_count, labeler`. Правило: человек считается, если видны голова и часть торса
(даже перекрытого); люди в дверях и на краю кадра считаются; отражения и фото на стенах нет.

## Файлы
- `gold_people.csv`, `gold_frames.csv` — НАСТОЯЩИЙ эталон: пока только заголовки, разметки ещё нет.
- `synthetic/` — ТЕСТОВЫЕ фикстуры (`video_id = synthetic_video`, разметчики `synth_*`), сгенерированы
  `make_synthetic.py` случайно. Они нужны только для проверки кода. Цифры по ним НЕ имеют отношения к реальным данным.
