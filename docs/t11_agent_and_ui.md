## Запуск (из корня `surveillance-assistant`)
```bash
pip install streamlit            # один раз
export LLM_BASE_URL=http://localhost:8000/v1   # адрес сервера модели
export LLM_MODEL=<имя модели на сервере>
export LLM_API_KEY=EMPTY
python -m streamlit run agent/app.py
```
В боковой панели можно выбрать режим базы: демо (SQLite с тестовыми данными) или PostgreSQL
(нужны `DATABASE_URL`, `psycopg2`). Папка клипов — `CLIPS_ROOT`; `clip_path` открывается только
внутри неё (выход через `../` и ссылки наружу блокируются). Если файла нет, страница покажет предупреждение.

Для демо без модели ничего запускать не нужно, кроме сервера модели: функции работают на seed-данных.
`EMBEDDER=hashing` включает тестовый эмбеддер для демо; в боевом режиме не задавайте (будет BGE-M3).

## Две цифры по 30 вопросам
```bash
python -m eval.eval_agent                 # демо-база, допуск по времени 0.0 с
python -m eval.eval_agent --db postgres   # если в PostgreSQL загружены database/seed*
```
Печатаются: правильная функция (первый вызов совпал с `expected_tool`; для вопросов вне базы — функций
не вызвано), верные аргументы (строго, без значений по умолчанию) и **верный ответ**. Также разбивка
по типам и файл `eval/results/<время>_<модель>.csv` с ответом на каждый вопрос.

Ограничения оценки:
- грейдер грубый (правила по первому слову, числам и временам); **CSV стоит просмотреть вручную**;
- эталоны посчитаны для варианта VLM `A` на seed-данных (`DEFAULT_VLM_VARIANT = "A"` — временное допущение);
- допуск по времени `--time-tol` по умолчанию **0.0**: команда его ещё не подтвердила, значение не зашито;
- GPU: если модель и VLM делят одну карту, запускайте оценку, когда VLM не работает.

## Как устроен агент
1. Модель получает системный промпт и шесть функций (`debug_*` ей недоступны, `vlm_variant`/`view` — тоже).
2. Вызов проверяется (`call_tool`): неизвестная функция или лишний аргумент — ошибка, возвращаемая модели; внутренние ошибки наружу без подробностей.
3. Модели возвращается урезанный результат, интерфейсу — полный (с `clip_path`).
4. Не более `max_steps` (5) шагов; сбой связи с моделью — сообщение, а не падение.
5. Видимость событий (`needs_vlm`/`confirmed`) обеспечивается в `agent/tools.py`; здесь она не менялась.

## Открытые вопросы для команды
Основной вариант A/B; значения `source`; `clip_path` или `keyframe_path`; допуск по времени; порог
`min_score`; pgvector или перебор; какая LLM (выбор замером); язык описаний функций (сейчас английский).
