# Формат events.json

Один файл на одно видео. Пишет CV (Арай), читает загрузчик базы (Айгерим), VLM-поля заполняет Панда.

## Корень файла

| Поле | Тип | Описание |
|---|---|---|
| `video_id` | строка | имя видео (для MEVA: имя файла без расширения) |
| `camera_id` | строка | идентификатор камеры |
| `source` | строка | откуда видео: `own`, `meva`, `warehouse` |
| `fps` | число | частота кадров видео |
| `events` | список | события |

## Событие

| Поле | Кто заполняет | Описание |
|---|---|---|
| `event_id` | CV | `cv_0000`, `cv_0001`, ... |
| `event_type` | CV | тип события, например `pickup_or_put_candidate` |
| `track_id` | CV | номер трека человека |
| `zone_id` | CV | зона, в которой произошло событие |
| `t_start`, `t_end` | CV | секунды от начала видео |
| `trigger_score` | CV | уверенность триггера, может быть `null` |
| `needs_vlm` | CV | нужно ли отдать клип в VLM |
| `clip_path` | CV | путь к вырезанному клипу (2–8 с) |
| `detected_by` | CV | кто нашёл событие, сейчас всегда `cv` |
| `vlm_status` | Панда | `not_checked`, `confirmed`, `rejected`, `error` |
| `vlm_event_type` | Панда | `pick_up`, `put_down` или `none` |
| `vlm_description` | Панда | описание клипа (на английском) |
| `prompt_variant` | Панда | `A` (только клип) или `B` (клип + track_id, зона, время) |

## Три решения

1. Имена полей общие для всей команды: `video_id`, `event_type`, `t_start`, `t_end`, `zone_id`, `camera_id`.
2. `source` в корне означает источник видео. Кто нашёл событие, хранится в `detected_by`.
3. Тип `pickup_or_put_candidate` вместо отдельных «взял» и «положил»: по геометрии это не различить. Решает VLM и пишет результат в `vlm_event_type`.
